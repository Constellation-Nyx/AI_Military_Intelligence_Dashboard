# AI-Based Military Intelligence Dashboard

AI-assisted Streamlit multipage dashboard for exploratory analysis of the UCDP Georeferenced
Event Dataset (GED) v26.1, including interactive geospatial analysis, country-level analysis,
violence-type prediction, threat-level assessment, forecasting, AI-assisted intelligence
summaries, and data exploration.

This project analyzes **historical, publicly documented conflict-event records for academic
purposes only**. It performs no real-time data collection and must not be used for operational
military decision-making or targeting.

## Setup

Install the required Python packages:

```bash
pip install -r requirements.txt
```

The UCDP GED CSV is not included in this repository.

### 1. Add the dataset

Place the GED CSV file at:

```
data/GEDEvent_v26_1.csv
```

### 2. Train the violence-type prediction model

If the trained model artifacts are not already present, run:

```bash
python train_violence_model.py
```

This creates the `models/` directory containing:

- `violence_type_model.pkl`
- `feature_encoders.pkl`
- `target_encoder.pkl`

### 3. Run the application

```bash
streamlit run app.py
```

### Optional PyDeck support

The Global Threat Map supports PyDeck as an optional WebGL-based renderer. If PyDeck is
installed, the map can use a WebGL `ScatterplotLayer`. If PyDeck is unavailable, the
application automatically falls back to Plotly.

```bash
pip install pydeck
```

## Dashboard modules

1. **Home** (`app.py`) — dashboard overview, KPIs, navigation.
2. **Global Threat Map** — interactive geographic visualization of events, with automatic
   downsampling and optional PyDeck WebGL rendering.
3. **Country Analysis** — country- and region-level incident analysis and trends.
4. **Violence Type Prediction** — RandomForest-based prediction of violence category
   (state-based / non-state / one-sided) from event context and casualty data.
5. **Threat Level** — severity classification (Low/Medium/High), shown as an explicit
   leaked-vs-corrected comparison (see below).
6. **Forecasting** — historical trend analysis and estimated future incident counts.
7. **AI Intelligence** — automated, rule-based intelligence summaries.
8. **Data Explorer** — filtering, exploration, and gzip-compressed data export.
9. **Settings** — dataset/model validation and cache controls.

## Design system

`utils/theme.py` — centralized dark "operations-style" theme: color tokens, typography, and
shared Plotly styling.

`utils/components.py` — reusable interface components: page headers, KPI cards, classification
banners (warning / danger / ok), threat badges, section labels.

`utils/state.py` — shared application state via `st.session_state`, including the global
year-range filter, region/country filters, default country, forecast-horizon setting, and
prediction-confidence-threshold setting. Filters persist as you move between pages.

`utils/insights.py` — rule-based summary generation for the AI Intelligence page.

## Data loading and caching

The application uses a shared `load_data()` function (`utils/data_loader.py`) so every page
reads from the same pipeline. The CSV is loaded with Pandas and cached via
`@st.cache_data`. Missing values in `adm_1`, `adm_2`, and `source_headline` are filled with
`"Unknown"` during loading; this is disclosed on the Settings page.

## Global Threat Map

- **Automatic downsampling** — `DOWNSAMPLE_LIMIT = 20,000`. When the filtered dataset exceeds
  this and auto-downsampling is enabled, a random subset is shown for interactive performance.
  This limit applies only to the map visualization, not to any analytical or ML component.
- **PyDeck WebGL rendering** — optional `ScatterplotLayer` renderer for large point sets.
- **Plotly fallback** — `px.scatter_mapbox(...)` used whenever PyDeck is unavailable or not
  selected.

## Data Explorer

- Row display options: 100 / 1,000 / 5,000 / All.
- Requesting more than 10,000 rows requires an explicit confirmation checkbox.
- Full filtered data can be downloaded as a gzip-compressed CSV to keep payloads small; the
  currently displayed rows can also be downloaded uncompressed.

## Machine learning

Two classification tasks, with two very different leakage profiles:

### Violence Type Prediction

Predicts `violence_type_label` (state-based / non-state / one-sided) from country, region,
month, year, event-clarity/precision codes, number of sources, **and casualty fields**
(`deaths_a`, `deaths_b`, `deaths_civilians`, `deaths_unknown`, `best`, `high`, `low`). Casualty
fields are legitimate features here because the target is not derived from them — this is not
a leakage case.

Trained via `train_violence_model.py` on an 80/20 split; the trained artifacts are loaded
(not retrained) by the Streamlit page. Prediction runs only after explicit form submission.

### Threat Level (severity)

Severity labels (Low/Medium/High) are derived directly from `best` (fixed thresholds: 0–1 / 2–9
/ 10+). Because the label comes from a casualty field, the page trains **two** models and shows
both side by side:

- **Leaked model** — includes `best`, `high`, `low`, and the per-side death fields as features.
  Produces an inflated, near-perfect-looking accuracy that is **not** genuine predictive skill,
  because the model can largely read the label back off its own inputs. Clearly labeled as
  leakage-driven on the page.
- **Corrected model** — context-only features (`type_of_violence`, `region`, `country`, `month`,
  `year`, `date_prec`, `where_prec`, `event_clarity`, `number_of_sources`), with no casualty
  information. This is the honest evaluation.

Both are RandomForestClassifiers, cached via `st.cache_resource` to avoid retraining on every
interaction.

### Forecasting

Linear Regression fit on the trailing 24 months of the current filter selection, extrapolated
forward. R² of the trend fit is reported alongside the forecast so the estimate's reliability
is visible, and results are explicitly labeled as estimates, not predictions.

## Running the tests

```bash
pytest tests/
```

Tests cover severity-label thresholds, the leakage guard (asserting the corrected model's
feature set never includes a casualty-derived column), and the anomaly-detection/forecasting
logic, using small synthetic time series rather than the (unshipped) GED CSV.

## Dataset

This repository does not include the UCDP GED dataset. Obtain it separately from the Uppsala
Conflict Data Program and place it at `data/GEDEvent_v26_1.csv`.

The dataset used in this project contains 417,968 events (28 columns used by the app, out of
49 in the raw file) covering 1989–2025 across 126 countries.
